## Palaišana
Pirms palaišanas izdarīt:  
`pip install -r requitments.txt`  
Pēc tam prototipu var palaist ierakstot:  
`python ./main.py`  

## Apraksts
Prototips tik veidots balstoties uz iepriekš izveidotajiem ***prasību specifikācijām*** un ***sistēmas projektējuma***.  
Prototipā var:  
 - Pievienot karti;
 - Rediģēt karti;
 - Dzēst karti;
 - Apskatīt statistiku;
 - Sakārtot kartes pēc pievienošanas, "*atrašanās vietas*", statistikas un alfabēta.
